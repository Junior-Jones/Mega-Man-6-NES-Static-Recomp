MEGA MAN 6 NES STATIC RECOMPILATION - WINDOWS BUILD

Run Launcher.exe. Place a legally supplied Mega Man 6 (USA) ROM in the Rom
folder, or choose Browse ROM. The launcher accepts only the exact supported ROM;
the ROM is not included.

The accessible Windows launcher supports keyboard and gamepad input, SDL3
video and audio, pause and resume, windowed and full-screen play, scaling,
snapshots, screenshots, and launcher shortcuts.

Press F1 for controls and shortcuts. Escape switches between gameplay and the
launcher without resetting the static core.

Version 1.2.0 keeps every frontend choice in one portable settings.ini file,
including first-run Welcome state, remembered ROM folder, display, audio,
Auto-Run, Player 1 controls and gamepad mappings. Mega Man 6 is single-player;
controller port 2 is inactive.

F8 now captures the exact displayed framebuffer with collision-safe file names.
The static core is losslessly compacted while retaining all 25,156 explicit
bank-and-address identities and no runtime opcode interpreter or fallback.
Wide Screen is not included in version 1.2.0.
